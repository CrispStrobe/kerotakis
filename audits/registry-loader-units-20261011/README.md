# Runtime registry unit admission

Separate from the scalar-bound repair in [PR778](https://github.com/CrispStrobe/kerotakis/pull/778), this tranche asks whether mandatory runtime properties honor their declared units. The [20-control freeze](freeze.json) pins final source `f515781d` before execution. The [first local baseline](local-first-baseline-review.json) records **6 pass / 14 fail**, with unchanged test identities and fixture hashes, exit101 and no ignored or filtered controls. Independent review confirms the outcomes and metric factors. All2,245 source files were byte-compared before injecting the fixture; the separately generated offline lock differs from the hosted lock in17 package versions.

Current canonical registry values and equivalent scale-one aliases remain supported. Runtime inputs in kg/mol, kg/m3 and kJ/(mol.K) must either convert to the existing SpeciesData units or explicitly refuse for units. They currently enter as raw values and fail numeric-equivalence checks. Typed validation checks declared dimensions but admits some incompatible or unknown symbols; correctly hashed packs likewise admit malformed unit metadata. Pack-to-runtime checks preserve the distinction between a valid metadata-bearing typed document and an incorrectly interpreted runtime value.

Next: validate one shared unit policy using the existing `units.rs` normalizer, checking both declared dimension and symbol. Runtime/generated construction must consume canonical values. Typed validation and pack admission must check semantics while retaining valid alternate-unit metadata and round-trip behavior. Preserve canonical values, reviewed aliases, zero-Cp records and signed energies. Do not use a canonical-string-only gate that rejects existing valid aliases. Keep this work on a separate source branch fromPR778, and preserve the first failures.

Require the unchanged20 paired controls, the two separately frozen and passing [alias numeric-equivalence controls](supplemental-baseline-review.json), all21 scalar controls, complete affected core/data/safety libraries and registry suites, formatting/lint, and fresh source-bound hosted checks. New schema-wide unit rules, polynomial coefficients, provenance and MgCl2 measurements remain outside this narrow repair. No unit repair has been applied or accepted yet.
