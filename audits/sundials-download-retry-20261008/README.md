# CI-01: bounded SUNDIALS download retries

[The first #771 native-host failure](../integration-20261008/native-controls/pr771-dec6-native-host-first-failure.json) occurred before compilation: curl could not connect to GitHub while downloading the checksum-pinned SUNDIALS release. The same-head retry passed and #771 is now merged; [the retry receipt](../integration-20261008/native-controls/pr771-dec6-native-host-retry.json) preserves that resolution separately.

[Prepared commit ed30ae52](https://github.com/CrispStrobe/kerotakis/commit/ed30ae5276340d30ccbfd92f31cb85d61988205b) changes only `tools/fetch-sundials.sh`: 15-second connection timeout, 120-second transfer limit, three retries with two-second delay, a 180-second retry window, and connection-refused retry support. The last transfer can extend beyond the retry window, within its transfer limit. Version, release URL, pinned SHA-256, checksum failure, extraction and existing-source behavior remain intact.

[The lightweight local review](review.json) uses real curl and a tiny deterministic archive on a loopback HTTP server. Fixture copies replace only release URL and expected digest; they do not download upstream SUNDIALS or compile anything. Original script fails the transient 503 after one request; candidate succeeds after two. Candidate rejects a wrong checksum without publishing source, stops after four persistent-503 requests, and skips downloading existing source. All five expected control outcomes, shell syntax and diff checks pass. This does not reproduce the original 75-second connection timeout or establish a successful upstream build.

[PR #772](https://github.com/CrispStrobe/kerotakis/pull/772) passed all five required gates on `8037f0696e76af29be25590bde7a9fcb129db51a` and merged as `0af91885876f8acc8d237165fc52a01daada2412`. The script was the only production diff relative to its main base. This establishes hosted acceptance of the fetch change; no induced live upstream outage, chemistry-model or application-performance claim follows. The original download failure and lightweight fixture qualifications remain immutable.
