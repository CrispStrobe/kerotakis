# Fifteen prospective mechanism CLI migration controls

The [manifest](manifest.json) freezes exactly fifteen independent command invocations before execution: six inspect commands (JSON and text for each of the three shipped packs), three instantaneous-rate commands, one bounded inert-only simulation, one complex-note equivalence inspection, and four refusals. All commands, input hashes, exact IDs, CLI/parser source hashes and expectations are bound to the reviewed dependency candidate. These are source-informed engineering controls, not independent blind chemistry forecasts.

The [collector](collect.py) checks binary, manifest, collector, source and input hashes before starting. It refuses an existing evidence destination, runs commands sequentially with a twenty-second timeout each, and captures every command, stdout, stderr, exit, timeout and launch error even when a control fails. Successful JSON must have the declared schema, finite values, complete species/reaction identities and consistent progress accounting. Human inspection must include every declared reaction. The complex annotation must preserve the full ordinary pack inspection JSON. Refusals bind exact exit codes and diagnostic categories without pinning parser-specific wording.

The simulation runs only nitrogen in the hydrogen/oxygen pack for 0.0001 seconds with two sample intervals. Its inventory and pressure should remain unchanged and reaction extents should be empty. The instantaneous-rate cases use tiny active feeds at 1500 K in one litre. This is a mechanical migration input: it makes no claim that every reaction's published calibration range overlaps at that temperature. No reaction yield, measured rate magnitude, ignition delay or active stiff-integration accuracy is forecast.

Pack source and derived input attribution: Kerotakis gas-phase mechanism packs, CC BY 4.0. The three original repository files retain their provenance; the complex-note witness is a separately identified derived annotation mutation.
