# Source-informed fleets v3: cases 777–896

Status: frozen before execution on 2026-09-13. GitHub CI owns the first run;
the deployment VPS does not build the release CLI or execute the fleet.

This tranche converts five reviewed, previously unexecuted candidate families
from the private research inventory into 120 original Kerotakis scripts:
water-energy accounting, defined aqueous selectivity, dilute ionic
conductivity, metal-ligand perturbations, and signed ideal organic equilibrium.
Each family contains 24 distinct scripts in six four-case relation groups.
The public contract contains no source identity, URL, edition, page mapping or
source prose.

The first run is diagnostic evidence, not a promise that every expectation
passes. Raw stdout, stderr, events, final benches and refusals are retained
even on failure. Scientific assertions are frozen before execution and may
not be weakened to fit output. An invalid script may be repaired only when the
intended operation is unambiguous; a model failure or unsupported claim stays
as evidence and becomes an explicit gap.

The aggregate gate requires five reports, 120 cases, 30 named relations and
150 execution-plus-relation checks from one revision-bound CLI artifact.
Parallelism is capped at four. Promotion remains a later review: only a
distinct concept with a learner-visible comparison, complete EN/DE content,
explicit learning progress, safety/apparatus metadata and a semantic assertion
may enter Experiments, Codex or Missions.
