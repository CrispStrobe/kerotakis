# Source-informed fleets v2: cases 489–776

Status: architecture frozen before authoritative execution. This second corpus
does not alter or reinterpret the archived 219–458 evidence.

The programme contains twelve families of 24 original scripts: quantitative
solutions, polyprotic/carbonate systems, redox cells, gas production and
transfer, phase/colligative behaviour, crystallisation boundaries, separation
trains, kinetics boundaries, household biochemistry, materials transport,
analytical observables and thermochemical paths.

Every case participates in a substantive conservation, independent-law,
metamorphic or explicit-boundary relation. Merely observing an event does not
qualify a case. Exact scripts, relation participants, directions and numerical
tolerances are committed before the first engine execution; failed evidence is
preserved and expectations are never widened from observed output.

## Public/private boundary

Public manifests contain original Kerotakis questions, scripts and generic
scientific relations only. Source identities, editions, locations, licence
notes and source-to-case mappings remain in the private research record. The
validator rejects source/citation fields and common URL, ISBN and DOI tokens;
CI artifacts therefore contain no private source mapping.

## Execution contract

- One release CLI is built by GitHub and its SHA-256 binds every shard.
- Twelve family shards each run 24 scripts sequentially in isolated processes.
- Matrix parallelism is capped at four; no fleet workload runs on the VPS.
- Raw script, stdout, stderr, diagnostics, final bench and timeouts are uploaded
  under `if: always()` whether analysis succeeds or fails.
- The analyzer rejects missing/malformed/nonfinite evidence, negative or
  unregistered inventory, solver failures and violated named relations.
- The aggregate requires exactly twelve reports, 288 cases, IDs 489–776,
  80 named relations and 368 total execution-plus-relation checks.

This is evidence for behavior inside declared model domains, not empirical
certification. Unsupported rate, nucleation, apparatus-efficiency, calibration
or sensory claims must remain explicit boundaries.

## Promotion gate

A representative may enter Experiments, Codex or Missions only after its whole
relation group passes and review confirms a distinct teaching concept, a
learner-visible comparison, complete English/German content, explicit learning
progress, honest ingredients/apparatus/safety/boundary metadata and a catalog
semantic assertion. Parameter-only variants remain regression evidence.
