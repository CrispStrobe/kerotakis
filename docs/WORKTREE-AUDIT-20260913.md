# Development-history preservation gate

Machine-specific worktree inventories are maintained privately. This public gate is not a deletion instruction. Re-authored pull requests can absorb behavior without preserving commit ancestry or byte-identical patches.

Before removing a development checkout, compare unique changes by intent and behavior with merged work, preserve evidence and tests absent from the destination, and verify that authored changes or active processes cannot be lost. Until that semantic review is complete, retain the work. Historical inventory counts are not a current cleanup authorization.
