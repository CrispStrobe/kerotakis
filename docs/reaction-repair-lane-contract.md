# Independent reaction-repair lanes

The user authorized two independent lanes on2026-10-16. The protocol agent
repairs command syntax, explicit procedures and proven naming aliases; the
independent model agent repairs underlying chemical/physical models. Their
source and validation work may proceed in parallel, with per-fix prerequisites.
Use the [ready-to-use model-agent handover](independent-model-agent-handover.md).

| Owner | Writes | Does not silently substitute |
| --- | --- | --- |
| Protocol agent | Corrected scripts, prospective expectations, alias input/stock controls; shared queue/STATUS reconciliation | Counterions, phases, hydrates, catalysts or different molecules |
| Model agent | Solver/mechanism/data fixes; its own model-followup evidence and status | Warnings for implemented chemistry, process exits for physical passes |

Protocol follow-ups belong in
`audits/reaction-dataset-200-20261015/protocol-followups-20261016/`.
Model follow-ups belong in
`audits/reaction-dataset-200-20261015/model-followups/<issue-id>/`.
Model intake belongs in `model-issues-20261016/` under the same audit directory.

Each intake record must identify original ranks/IDs, immutable original script
hashes, corrected-script path/hash when available, prospective expectations,
observed source/binary/lock/script binding, actual result and remaining gap.
Include a minimal reproducer, classification, implicated code and explicit
positive/negative acceptance. Unexecuted records must say so; source analysis
alone cannot establish a reproduced defect. An issue may be resolved by a
correct procedure, a genuine alias, a product repair or an honest coverage limit.
Record those outcomes separately.

The model agent appends its own evidence/status referencing the issue ID. It
must not concurrently rewrite shared counts or the protocol agent's files.
The protocol agent imports completed model results only after reviewing their
bindings and limits. Preserve all first reports; add follow-ups separately.

Execution success, identity acceptance, principal-response agreement, full
supported-domain acceptance, integration and deployment are separate fields.
Track supplied-case IDs independently from the larger working-script catalog.
Freeze new protocols before running them; never overwrite the original200 or
rerun an unchanged completed batch. Follow protected exact-head auto-merge and
all applicable acceptance. Public documents use repository/public paths only.
