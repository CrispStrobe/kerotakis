Kerotakis — politique de confidentialité Dernière mise à jour le 28 août 2026 · s'applique aux applications web, macOS et iOS

Kerotakis ne collecte rien, ne transmet rien et n'exploite aucun serveur. La chimie est calculée sur votre propre appareil. En mode avion, toutes les fonctions restent disponibles.

Quelles données sont collectées

Aucune. Il n'y a ni compte, ni connexion, ni analytique, ni télémétrie, ni rapport de plantage, ni publicité, ni pistage. Aucun identifiant n'est créé, lu ou partagé. Rien vous concernant, ni concernant votre appareil, ne quitte l'appareil.

Où votre travail est conservé

  • Votre laboratoire — récipients, historique des commandes et niveau de détail choisi — se trouve dans la mémoire de l'application en cours d'exécution, et sur le web également dans le stockage local du navigateur.
  • Les fichiers enregistrés (scripts .lab, cahiers de laboratoire et graphiques) ne vont que là où vous les déposez dans la boîte de dialogue d'enregistrement.
  • Les fichiers ouverts sont lus dans l'application et copiés nulle part ailleurs.
  • Rien de tout cela n'est téléversé. Effacer les données du site ou l'application supprime ces données.

Utilisation du réseau

Les applications macOS et iOS n'émettent aucune requête réseau de leur fait : les solveurs, les bases de données thermodynamiques et les leçons sont intégrés à l'application.

Un point de transparence, parce qu'il est vérifiable : la version macOS déclare le droit com.apple.security.network.client. Il ne sert pas à un usage réseau propre à l'application. macOS fait passer tout ce que charge la vue web intégrée — y compris les fichiers internes à l'application — par le processus réseau de WebKit. Dans le bac à sable de l'application, ce processus ne peut rien charger sans ce droit ; l'application n'afficherait qu'une fenêtre vide. Dans les deux cas, rien n'est envoyé.

La version web télécharge l'application et le moteur depuis le site qui les héberge et les met en cache pour une utilisation hors ligne ultérieure. L'hébergeur (actuellement GitHub Pages) peut tenir les journaux habituels d'un serveur web ; cela échappe à notre contrôle.

Enfants

Kerotakis convient à un usage scolaire. Comme aucune donnée n'est collectée, aucune donnée d'enfant n'est collectée non plus.

Tiers

Il n'y en a aucun. Ni SDK, ni régie publicitaire, ni service d'analytique. L'application contient des composants libres — avant tout IPhreeqc de l'U.S. Geological Survey — sous forme de bibliothèques locales, et non de services appelés.

Modifications

Si cette déclaration change, la nouvelle version paraîtra ici avec une nouvelle date. Un changement signifierait que l'application fait quelque chose qu'elle ne fait pas aujourd'hui ; ce serait dit clairement ici.
